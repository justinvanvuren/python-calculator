# Python Calculator

A simple menu-driven calculator built in Python as part of the Programming with Python course (Session 2 assignment).

## Features
- Add, subtract, multiply, divide
- Handles invalid input and division by zero gracefully

## Setup
This project uses [uv](https://docs.astral.sh/uv/) for environment management.

```bash
uv run src/calculator_project/calculator.py
```

## Usage
Run the app, choose an operation (1–4), enter two numbers, and get the result. Type `q` to quit.
